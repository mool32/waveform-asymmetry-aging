## Data and Code Availability Statement

All data used in this study are publicly available. The LEMON dataset is available from the Max Planck Institute Leipzig Mind-Brain-Body repository (https://ftp.gwdg.de/pub/misc/MPI-Leipzig_Mind-Brain-Body-LEMON/). The Dortmund Vital Study dataset is available on OpenNeuro (https://openneuro.org/datasets/ds005385).

All analysis code is publicly available on GitHub: https://github.com/mool32/waveform-asymmetry-aging
